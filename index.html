Город помнит Новосибирск

Официальная страница настольного приложения для подготовки и отправки исторических видеоматериалов в TikTok.

Политика конфиденциальности Условия использования

Назначение приложения

Приложение помогает владельцу проекта «Город помнит Новосибирск» планировать публикации и передавать подготовленные видеоролики в TikTok через официальный Content Posting API.

Как работает загрузка

  1. Пользователь входит в принадлежащий ему аккаунт TikTok и предоставляет приложению разрешение на загрузку.
  2. Пользователь выбирает подготовленный видеофайл на своём компьютере.
  3. Приложение отправляет видео в черновики TikTok.
  4. Пользователь проверяет материал и завершает публикацию в TikTok.

Приложение не предназначено для доступа к чужим аккаунтам и работает только после явного разрешения владельца аккаунта.
